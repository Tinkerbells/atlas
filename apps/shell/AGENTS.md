# AGENTS.md — apps/shell

## Styling

Use **CSS modules** or **component-scoped styles** for all styling needs.

### Rules

- Colors, typography, shadows, animations, gradients — use CSS modules or component styles.
- Do not use utility-class frameworks (Tailwind, UnoCSS, etc.) for application styling.

## Linting and typechecking

- Before committing, run `lint:fix` to auto-format and fix lint issues.
